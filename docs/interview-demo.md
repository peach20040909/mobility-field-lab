# 면접 시연 순서

1. 프로젝트 개요에서 금지하면 사라지는지, 다른 공유 기기로 옮기는지 질문을 설명합니다.
2. ‘예시 데이터로 둘러보기’를 눌러 합성 자료임을 밝힙니다.
3. 사진 판정 화면에서 미검수 기기를 선택합니다. A/B가 각각 판정하고 최종 조정 사유를 남깁니다.
4. 분석 대시보드에서 100m당 수, 분모가 표시된 방해·위험 비율, 위험 유형을 보여줍니다.
5. 지도는 조사 시작점이며 실제 경로나 정책 효과가 아님을 설명합니다.
6. 실제 조사 등록·사진 저장·CSV·백업 흐름을 보여줍니다.
7. 실제 AI 성능은 아직 검증 전이며, 팀 서버와 원자료는 후속 연결 단계임을 설명합니다.

초기 자료의 800m 계획 대신 최종 제출본의 400m 및 근처/먼 곳 각각 200m를 따릅니다. 개인 기기는 지표에서 제외하고 공유 여부가 애매하면 불명으로 남깁니다.
