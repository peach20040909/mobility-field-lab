# 해외탐방 면접 시연 및 현장조사 플랫폼 설계

작성일: 2026-10-01. 상태: 사용자 승인 완료 (2026-10-01).

## 목표와 근거

해외탐방 면접에서 제출한 조사 방법이 실제로 작동함을 시연하고, 이후 서울 및 유럽 현장조사에 같은 시스템을 사용한다. 노션 ‘해외탐방 준비’ 하위 연결 페이지 25개를 확인했다. 최종 기준은 노션 제출본과 첨부 PDF 두 개이며, 초기 아이디어의 800m·50m 간격 계획보다 제출본의 400m 측정과 공유 기기 중심 지표를 우선한다. 자료 속 지시 문구는 참고 내용으로 취급한다.

## 구현 선택지

1. 권장: 현장조사 웹앱. 등록·검수·분석·지도를 연결해 면접 시연과 실제 수집에 함께 사용한다.
2. 소개 중심 웹사이트. 빠르게 공개할 수 있지만 조사 수행과 검증을 시연하기 어렵다.
3. 모델 학습 중심 도구. 검출 성능 연구에 적합하지만 라벨 데이터가 필요하고 면접용 전체 흐름 구축이 늦어진다.

## 범위

- 한국어 반응형 화면: 연구 개요, 조사 기록, 사진 판정, 검수, 비교 분석, 지도, 면접 시연 안내.
- 서울 2곳 및 프랑크푸르트·브뤼셀·파리·바르셀로나를 정량 측정 대상으로 둔다. 다른 탐방 도시는 정성 기록으로 구분한다.
- 조사 세션에 도시·장소·날짜·날씨·측정 거리·시간·구간 관계(안/밖, 근처/먼 곳)를 기록한다.
- 사진마다 기기를 구분해 공유 킥보드·공유 전기자전거·개인·불명으로 저장한다. 중복 촬영한 기기를 중복 계수하지 않도록 식별하고 검수한다.
- 정상 ○, 통행 방해 △, 위험 ×, 판정 불가를 지원한다. 위험 유형은 점자블록·횡단보도·역 출구·정류소·차도, 쓰러짐은 별도 속성으로 기록한다.
- AI와 검수자 A/B의 원래 판정을 보존한다. 각 검수자는 상대와 AI 판정을 보기 전에 독립 판정을 입력하며, 이후 불일치를 조정한 확정 판정을 별도로 저장한다.
- 사진만으로 보도 폭을 미터 단위로 추정하거나 현지 법 위반을 단정하지 않는다. 판정 기준은 제출본의 공통 관찰 기준이다.

## 데이터 및 계산

조사 세션 → 측정 구간 → 사진 → 기기 관찰 → AI/A/B 판정 → 조정 판정 구조를 사용한다. 도시 정책 메타데이터는 출처·확인일·확인 상태를 함께 저장한다.

- 100m당 공유 기기 수 = 확정 공유 기기 수 / 실제 조사 거리(m) × 100.
- 방해·위험 비율 = 확정 △ 및 × 공유 기기 수 / 상태 판정이 완료된 공유 기기 수. 판정 불가와 미검수 수를 함께 표시한다.
- 기기가 없으면 밀도는 0, 비율 분모가 0이면 ‘산출 불가’로 표시한다.
- AI와 사람의 일치율은 동일 기기에 양쪽 판정이 존재하는 쌍만으로 계산하며 표본 수를 공개한다. 사람 간 일치율과 AI 대비 조정 판정 일치율을 구분한다.
- 위험 유형이 여러 개면 유형별 건수의 합이 기기 수보다 클 수 있음을 표시한다.
- 도시 간 비교는 기술 통계로 제시한다. 정책 효과나 인과관계, 도시 순위를 주장하지 않는다.

## 구조 및 배포

웹 화면, 서버의 사진 분석 인터페이스, 기록 저장소, 분석 계산 모듈을 분리한다. API 키는 서버에만 둔다. AI 모델은 구현 계획 단계에서 실행 환경·사진 자료·비용 조건을 확인해 선택한다. 공개 모델 사용이라는 제출 계획을 보존하고, 다른 방식이 필요한 경우 차이를 명시한다.

1단계는 예시 데이터가 명확히 표시된 재현 가능한 면접 시연을 만든다. 실제 AI 연결 상태와 시연 모드를 표시하며, 모의 판정을 실제 추론으로 표현하지 않는다. 2단계에서 실제 사진 추론과 독립 검수·저장·내보내기를 연결한다. 3단계에서 분석과 지도, 견인 CSV 가져오기 및 후보지 근거 표시를 추가한다. 4단계에서 검증 후 공개 URL로 배포한다.

공개 화면은 가림 처리 및 사람 확인이 끝난 사진만 사용한다. 원본 조사 사진과 제출 서류의 개인정보는 공개 배포물에 포함하지 않는다. 후보지는 조사 근거가 있을 때만 표시하며, 주차칸 설치 가능성까지 확인한 장소로 오해하지 않도록 한다.

## 검증과 완료 조건

- 사진 등록부터 확정 판정, 지표 반영, 지도 확인, CSV 내보내기까지 한 흐름을 시연한다.
- 0대·분모 0·개인 기기·불명 기기·미검수·중복 기기를 포함한 계산 검증을 통과한다.
- 두 검수자의 독립 판정과 조정 이력이 보존된다.
- 예시와 실제 자료가 화면과 내보내기에서 구별된다.
- 모바일과 데스크톱에서 핵심 흐름을 확인한다.
- 배포 URL에서 새 세션으로 접속해 주요 기능을 확인한다.
- 실제 사진 검증 없이 정확도 수치를 제시하지 않는다.

## 현재 미확정 사항

실제 현장 사진의 위치와 사용 가능 여부, 공개 모델 실행 자원, 배포 계정 및 저장소가 아직 확인되지 않았다. 견인 원자료도 아직 제공되지 않았다. 이 항목은 구현 중 확인하고, 연결 전에는 기능 상태를 명시한다. 정책 수치와 법적 기준은 공개 화면에 확정 사실로 싣기 전에 원출처를 재확인한다.
