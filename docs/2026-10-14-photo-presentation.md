# 인도지킴이들 현장 사진 시연

사진 선택 → 로컬 AI 분석 → 번호가 표시된 사진·큰 판정 카드·근거 → 동일 결과 인쇄/PDF 및 JSON 저장.

전용 주소: https://peach20040909.github.io/mobility-field-lab/demo/

## 시연 순서

1. GPU 환경이 설치된 이 작업 폴더에서 PowerShell로 `./scripts/start-demo.ps1` 실행. 서버가 준비되면 토큰을 클립보드에 복사하고 공개 시연 페이지를 연다.
2. 연결 토큰 칸에 붙여넣고 `AI 연결 확인`. 브라우저가 요청하면 로컬 네트워크 접근 허용.
3. 조사 장소 입력, 홍대 사진 선택, `AI 분석 시작`.
4. 번호별 기기 종류·판정·근거를 설명. `결과 인쇄 / PDF`로 같은 결과를 자료로 만든다. `결과 JSON 저장`으로 분석 시각·모델·원문 판정을 보관한다.

## 데이터와 모델

- 친구가 만든 Claude 판정 자료와 이 화면의 Qwen3-VL-2B 판정은 별개다. 원래 자료와 일치한다고 주장하지 않는다.
- 사진은 브라우저에서 이 PC의 루프백 서버로만 전송한다. 전용 시연 화면은 사진·토큰·결과를 영구 저장하지 않는다. 새로고침 전에 필요한 결과를 내보낸다.
- AI 예비 판정은 사람의 검수 전 결과다. 조사 대시보드 및 지도 통계에 자동 반영하지 않는다. 기존 조사 도구의 독립 검수를 이용한다.
- 친구 PC에서도 별도 로컬 AI 환경이 필요하다. GitHub Pages가 AI 서버를 제공하지 않는다.
- 실제 업로드 화면에서 예시 결과를 자동으로 넣지 않는다. 연결·모델·응답 검증 실패는 오류로 표시한다.
- 정상은 "정상 추정"으로 표시한다. 정상에는 연속적인 통행 경로가 보여야 한다는 기준으로 프롬프트를 보완했으나, 실제 `_10` 사진은 여전히 정상 응답이었다. 화분·시설물 사이 기기 배치의 통행 방해 가능성을 AI가 놓칠 수 있으므로 사람의 검수가 필요하다. 정확도 개선을 검증했다고 주장하지 않는다.
- 기기 수는 모델의 탐지 건수로, 완전한 실제 기기 수나 검증된 정확도가 아니다. 사진만으로 보도 폭 또는 법적 위반을 확정하지 않는다.
- 공개 저장소에 원본 홍대 사진·실제 판정 PDF·연결 토큰을 올리지 않는다. 배포 전 검증 파일은 무시된 `services/vision/results/`에 둔다.

## 검증

- Vitest 49건 및 Python 계약/API 24건 통과.
- 일반 브라우저 E2E 12건 통과, GPU 실사진 테스트 2건은 일반 실행에서 생략.
- 사진 변경 시 오래된 디코딩이 새 사진을 덮지 않는 회귀 테스트.
- 390·768·1440px 폭 및 세로 사진 인쇄 비율 확인.
- 전용 페이지 실제 홍대 사진 GPU 분석·사진 영역·판정·모델 기록·PDF 생성 확인.
