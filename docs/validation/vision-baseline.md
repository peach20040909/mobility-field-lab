# 로컬 공개 모델 연결 검증

2026-10-01. Qwen/Qwen3-VL-2B-Instruct, revision 89644892e4d85e24eaac8bacfd4f463576704203, Apache 2.0. Windows RTX 3050 Laptop 4GB에서 NF4 4bit, PyTorch 2.5.1 CUDA 12.1로 실행했다.

홍대 원본 폴더의 31 JPG 중 내용이 같은 6쌍을 제외하면 25장이다. 원본은 공개 저장소에 포함하지 않았다. .jpg 파일이 실제로는 MPO로 디코딩되는 휴대폰 사진을 확인해 첫 프레임 읽기를 지원했다.

단일 기기가 크게 보이는 사진에서 실제 GPU 추론이 21.51초에 유효한 관찰 1개를 반환했다. bbox와 공유 전기자전거 제안을 반환했지만 이유 문장에는 scooter라는 단어를 사용해 일관성이 부족했다. 이 제안은 확정 판정이 아니다.

기기가 많이 겹친 사진에서는 약 56초 제한에 걸려 JSON이 잘렸다. 해당 결과는 저장하지 않았다. 초기 프롬프트의 필드 누락과 루트 구조 오류도 거부했다. 이후 모델 입력 계약을 JSON 배열·0..1000 좌표로 정하고, 서버가 검증 후 앱 계약인 observations 객체·0..1 좌표로 변환한다. 누락 필드를 채우거나 잘린 응답을 복구하지 않는다. 정상 EOS 종료도 요구한다.

아직 20장 이상의 독립 정답 라벨이 없으므로 유형별 정확도·일치율을 보고하지 않는다. 남은 사진을 검출 수와 공유 여부·상태별로 두 사람이 독립 검수하고, 누락 및 불일치 유형을 기록해야 한다.

실제 로컬 API에 사진을 업로드하고 AI 관찰을 저장한 뒤 독립 검수 화면과 bbox를 확인하는 브라우저 테스트가 24.6초에 통과했다. 새로고침 후 기록도 보존됐다. 자동 테스트는 AI/저장소 10개를 포함한 TypeScript 46개와 Python 계약·API 24개, 일반 브라우저 흐름 4개다. 실제 사진 시험은 별도 1개이며 CI에서는 GPU와 사진이 없어 건너뛴다.

독립 코드 검토에서 발견한 연결 시 토큰 미검증과 생성 EOS 미확인도 수정하고 회귀 검증했다. 팀 인증·공동 저장은 이 연결에 포함하지 않는다.
