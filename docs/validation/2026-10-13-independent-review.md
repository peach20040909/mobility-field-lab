# 사진 판정 점검과 수정

## 점검 전

A/B 제출 저장, 원판정 변경 금지, 두 제출을 요구하는 최종 조정 저장, 사람 간 일치율, IndexedDB 보존이 있었다. 하지만 화면의 최종 조정 탭이 제출 전에도 열려 상대 결과가 보였고, 일치율은 기기 종류와 주차 상태만 비교했다. 미확정 기기도 밀도에 포함됐으며 지도는 조사 시작점만 표시했다.

## 수정

- 상단 판정자 A/B 전환. 두 사람이 모두 제출할 때까지 상대와 AI 결과·메타데이터를 숨기고 최종 조정 탭을 비활성화한다. 제출한 본인 기록은 보여준다.
- 종류·상태·위험 위치·쓰러짐으로 일치/불일치를 표시한다. 위험 목록 순서와 자유 입력 사유는 비교하지 않는다. 공유 불명·판정 불가·한쪽 미제출 쌍은 일치율 분모에서 제외하고 제외 수를 공개한다.
- 최종 조정에서 A/B 분류·위험·사유를 비교하고 선택한 판정을 불러온 뒤 조정 사유를 입력한다. A/B 원판정과 조정 이력은 보존한다. 최종 조정이 끝나도 원판정의 불일치 표시는 유지한다.
- 확정 공유 기기만 100m당 수에 포함하고, 확정 상태 중 판정 불가를 제외한 표본으로 방해·위험 비율을 계산한다.
- 조사 시작점의 지도 팝업에 확정 수·밀도·방해율·미확정 수를 표시한다. 확정 방해·위험이 있으면 주황, 없으면 초록, 상태 판정 표본이 없으면 회색이다. 개별 기기의 위치나 실제 보행 경로를 생성하지 않는다.
- 30초 판정 예시 버튼: 일치 3건·불일치 2건·미제출 1건, 초기 유효 쌍 일치율 60%. 기존 예시와 다른 ID를 사용하고 별도로 집계한다. 다시 실행해도 저장한 원판정·조정을 덮어쓰지 않는다.

## 검증

실패 테스트를 먼저 확인하고 수정했다. 단위 49개 통과, 일반 브라우저 10개 통과, 실제 GPU 사진 시험 1개는 이번 범위에서 미실행. 타입 검사·lint·정적 빌드 통과. 독립 읽기 전용 코드 검토에서 주요 결함 없음.

E2E로 제출 전 비교 비노출·최종 조정 비활성화, B 제출 후 불일치, 조정 후 A/B 사유 보존을 확인했다. 짧은 예시는 조정 전 확정 3대/400m(0.75대/100m), 위험 1대를 추가 확정하면 4대/400m(1대/100m), 방해·위험 25%다. 대시보드와 지도 팝업이 같은 수치를 표시하고 새로고침 후 보존한다.

## 저장과 역할 경계

모든 조사 데이터·사진·판정은 해당 origin의 브라우저 IndexedDB에 저장한다. 다른 브라우저·기기와 자동 공유하지 않는다. A/B는 인증 계정이 아니라 한 기기의 화면 역할이다. 개발자 도구·백업 또는 의도적인 역할 변경을 막는 보안 경계는 아니다. JSON 백업·복원은 제공한다.

짧은 예시 흐름: 메인 30초 판정 예시 → 최종 조정 → B 판정 불러오기 → 조정 사유 → 확정 저장 → 분석 대시보드·조사 지도. 모든 해당 화면은 예시임을 표시한다.
