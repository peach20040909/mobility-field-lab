# 1차 시연본 검증

2026-10-01 로컬 검증: 단위·저장소 테스트 36개, Playwright 3개 통과. lint와 타입 검사 통과. GitHub Pages 기본 경로를 사용한 Next 정적 빌드 성공.

독립 코드 검토에서 발견한 백업 용량 제한, 오래된 백업의 판정 덮어쓰기, 외부 이미지 주소 가져오기, 잘못된 중복 연결 그래프, 순서에 따른 중복 집계, 사진·기기 저장 원자성, 기기 없는 사진, 중복 해제 문제를 수정했다. 빈 조사 구간도 CSV에 포함한다. 지도 화면을 떠날 때 발생한 Leaflet 애니메이션 오류도 브라우저 테스트로 재현하고 수정했다.

기기 없는 사진 등록 후 새로고침 및 기기 추가, A/B 판정과 최종 조정, 실제·예시 구분, 390px 내비게이션, 지도 전환을 검증했다. 초기 테스트의 다른 조사 간 중복 연결 예시는 현재 가져오기 계약이 금지하는 입력이어서, 각 조사에 독립 대표 기록을 둔 유효 예시로 갱신했다. 잘못된 조사 간 연결 거부는 별도 회귀 테스트로 검증했다.

홍대 사전조사 폴더의 JPG 31개 중 SHA-256으로 같은 내용의 파일 6쌍을 확인했다. 고유 사진은 25장이고 모두 사진 등록 한도인 10MB 이하다. 첫 사진을 직접 확인했으며, 겹쳐 있는 여러 공유 이동수단과 출입구·점자블록 주변 장면이다. 아직 모델 추론이나 독립 정답 라벨을 생성한 것은 아니다. 사진 원본은 저장소에 포함하지 않았다.

현재 단계는 로컬 저장 시연본이다. 서버에서 보장하는 독립 검수, 계정·팀 동기화, 실제 AI 추론과 자동 가림, 견인 원자료 연결은 전체 계획의 남은 작업이다. 배포 성공은 별도로 확인한다.
