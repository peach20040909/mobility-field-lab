# 홍대 사전조사 시연

공개 바로가기: https://peach20040909.github.io/mobility-field-lab/#hongdae

## 준비된 내용

- 사용자 제공 폴더의 JPG 31개를 파일 해시로 중복 제거하여 25장 보관. 게시용 복사본은 1200px 이내로 축소하고 EXIF를 제외했다. 배경 인물·차량 식별 부위를 흐리게 처리했다. 원본 사진은 변경하지 않았다.
- 대표 사진은 레드로드의 SWING·카카오T 자전거 사진과 홍대입구역 8번 출구 사진이다.
- 사용자 제공 Claude 아티팩트의 6개 판정 항목 및 이유를 옮겼다. 사진 위 표시 영역은 자료의 표시를 옮긴 것이다. 이 사이트에서 모델을 실행해 검출했다고 주장하지 않는다.
- 모델 버전·분석 시각은 제공 자료에 없으므로 새 분석 메타데이터를 만들지 않았다. 출처는 데이터의 preparedSource 및 CSV에 보존한다.
- 두 사람의 A/B와 최종 판정은 **시연용 예시**다. 실제 조사자가 제출한 결과가 아니다. 03번은 A 정상/B 위험의 불일치를 조정하는 예시다.
- 추가 23장은 사진별 검토 메모를 붙였으며 **기기별 판정 완료 데이터로 간주하지 않는다**. 반복 각도와 근접 사진을 별도의 기기로 합산하지 않는다.
- 05번 노란 자전거 묶음은 2대 이상을 나타내는 항목이다. 정확한 대수를 모르는 묶음을 한 대로 취급하지 않도록 countMode=group을 저장하고 대수·비율 집계에서 제외한다. 비교 일치율에서는 자료처럼 한 개 판정 항목으로 비교할 수 있다.
- 지도 위치와 200m 거리는 **시연 설정**이다. 11개 실제 조사 지점·총 30대 등 배포 자료의 실제 조사 통계를 이 예시로 재현했다고 주장하지 않는다.

## 30초 동선

1. 바로가기에서 실제 사진과 저장된 사전 판정을 보여준다.
2. `불일치 조정 시연` → `최종 조정` → `B 판정 불러오기` → 예시 조정 근거 입력 → `확정 판정 저장`.
3. 닫기 → `숫자 보기` 또는 `분석 대시보드` → `조사 지도`.

서버·연결 토큰·실시간 모델 응답 없이 동작한다. 친구 기기에서도 같은 초기 예시가 열리지만, 각 기기의 조정 결과는 해당 브라우저에 저장된다. 예시를 다시 불러와도 사용자가 저장한 조정 기록을 덮지 않는다.

## 검증

Vitest 52건 통과. 초기 브라우저 전체 E2E 16건 통과(실 GPU 분석 테스트 2건은 이번 시연에 불필요하여 일반 실행에서 생략). 390·768·1440px 폭, 저장 예시의 사진 25개 응답, 금지 문구 검색, 모델 서버 호출 0회, 조정 후 대시보드·지도 반영, 재접속 시 조정 보존을 확인했다. JSON 복원과 CSV의 사진별 메모·기기 묶음 표시 보존도 테스트했다.
